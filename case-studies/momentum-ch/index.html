Link design08 / 13

Match the link style to its context.

Inline links are part of a sentence. Standalone links act as separate navigation choices.

Inline linkInside body text · underlined by default so it is easy to spot.
Standalone linkNo underline in the normal state · underline appears on hover.
Shared interaction statesVisible keyboard focus, disabled behavior, and theme colors.
Style and destination are separate choices.Either visual style can lead to another product screen or an external website.

Adoption11 / 13

Support the pattern. Catch new drift.

Actionable checks help teams follow the system without blocking them on unrelated legacy code.

Legacy color classesPoint new usage toward theme-aware utilities.
Raw inline stylesDirect styling into maintainable component styles and semantic variables.
Local image assetsGuide consumers toward the shared Momentum asset path.

Trade-off: new-code checks prevent new violations; they leave existing debt for planned migration.
